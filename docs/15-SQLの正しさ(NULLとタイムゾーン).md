# 第15問：SQLの正しさ（NULL意味論とタイムゾーン）

下記要件を満たす`Pull Request`を`feature`ブランチとして作成してください。

## 背景

集計系のエンドポイントが2つあります。いずれも一見正しく見えますが、**実データで動かすと誤った結果**を返します。原因の特定はあなたに委ねます。

- `GET /reports/inactive_users`：「一度もコメントしていないユーザー」を返すはずだが、結果が常に空になる。
- `GET /reports/daily_posts`：「日別の投稿数」を返すが、特定の時間帯の投稿で日付の境界がずれる。

## 要件

1. `inactive_users`が常に空になる原因を特定し修正する。
   - なぜ空になるのかを`notes/15-sql.md`に説明し、正しく該当ユーザーを返すよう直す。
   - 修正前後で**実際の件数**（誤＝0件、正＝該当ユーザー数）を示すこと。
2. `daily_posts`の日付境界がずれる原因を特定し修正する。
   - タイムスタンプはUTC保存です。集計の基準とすべき暦日（JST）との関係を踏まえて、境界がずれない集計に直す。
   - 月またぎ・タイムゾーン境界のケースを**再現データで検証**する。
3. 両不具合について、誤結果を再現するテストと、修正後に正しくなるテストを追加する。

## 受け入れ基準

- `inactive_users`が正しい該当ユーザーを返すこと。
- `daily_posts`が意図した暦日基準で正しく集計され、境界ケースで誤らないこと。
- 「なぜ誤っていたか」が`notes/15-sql.md`に再現付きで説明されていること。
