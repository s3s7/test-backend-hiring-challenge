# 第6問：サービス層へのリファクタリング（コントローラーの責務分離）


下記要件を満たす`Pull Request`を`feature`ブランチとして作成してください。

## 背景

あるコントローラーに業務ロジックが集中しており、テストしづらく可読性が低い状態です。責務分離を行います。

## 要件

1. 対象コントローラーの業務ロジックをサービスクラス（`app/services/`）に切り出す。
2. サービス層に対する単体テストを追加する（外部依存はモック/スタブ化すること）。
3. コントローラーはHTTPの受け渡しとシリアライズのみを行うようにする。
4. 変更に伴うAPIの挙動が変わらないことを統合テストで確認する。

## 追加要件

5. 主たる対象は肥大化した `PostsController`（`feed`・`export`・`publish` 等の業務ロジックを含む）とする。HTTPの受け渡し・シリアライズ以外のロジックをサービス層へ移すこと。

## 受け入れ基準

- サービスにロジックが移行され、ユニットテストと統合テストが正常に通ること。
