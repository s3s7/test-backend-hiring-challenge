# 第11問：観測性（ログ・メトリクス・トレース）導入

下記要件を満たす`Pull Request`を`feature`ブランチとして作成してください。

## 背景

現在はログがプレーンテキストで分かりにくく、問題発生時の原因追跡が困難です。可観測性を整備して運用性を向上させます。

## 要件

1. 構造化ログ（JSON）を導入し、リクエストID等のコンテキストを含める。
2. 基本的なメトリクス（リクエスト数、エラー率、平均応答時間）をアプリ側で計測・エクスポートする（Prometheus互換等の簡易実装で可）。
3. リクエストのトレースを導入（OpenTelemetry等の簡易実装で可）し、サンプル出力を`notes/11-observability.md`に添付する。
4. 導入に伴うパフォーマンス影響と運用フローを短くまとめる。
